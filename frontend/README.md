# MirissaStays frontend

This is the full original MirissaStays Next.js application copied from the local root app.

Deploy this folder as the Vercel frontend project. It currently uses the same Prisma-backed server rendering and API routes as the local app.

Required Vercel environment variables:

- DATABASE_URL
- JWT_SECRET
- NEXT_PUBLIC_SITE_URL
- ADMIN_EMAIL

Do not commit a real .env file or database password.
